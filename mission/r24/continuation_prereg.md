## 4. Gate（必须同时满足，机器判定）

### Gate-1 @ global 4000
| 指标 | 通过条件 |
|---|---|
| DEV ce_window | ≤ start（不上升） |
| **同口径 SAFE L1 vs CV** | **配对 CI 上界 < 0**（必须真正赢过恒速基线） |
| 夹爪 SAFE L1 | 不高于 start |
| 动作坍缩 | 预测 bin 的每任务不同取值数 > 1 |
| 数值健康 | 无非有限 loss、无 gnorm 爆炸（>100× 中位） |

### Gate-2 @ global 8000
Gate-1 全部条件，**外加**：
| 指标 | 通过条件 |
|---|---|
| 残差 R² | > 0（真正出现了可解释的残差信号） |
| 分层 | "still" 层的命令运动量显著高于 CV（这是闭环能否起动的前提） |

### 立即停止（任一触发即停并留证）
* DEV ce_window 连续 2 个记录点上升
* 预测退化为常数（某一任务所有帧同一 bin）
* 非有限 loss / 梯度
* 接口或契约不一致（normalizer sha、codec、相机顺序）

### 停止规则（比 Gate 更重要）
> **若 CE 继续下降而 Gate-1 的 "SAFE L1 vs CV" 仍跨 0，则停止增加步数**，
> 转入动作表征诊断（R24 §6 的方向），不再做同分布加步。
