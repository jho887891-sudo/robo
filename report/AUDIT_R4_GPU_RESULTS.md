关于“重复上一动作”基线的重要说明：本数据集里 `A[t−1] ≡ S[t]`（R1 已用数据验证 `A[t] = S[t+1]`），

## 11. 下一步研究建议

1. **把目标切换为残差是值得的，但还不能直接开 3000 步**：本轮的残差优势是“同样 300 步、同样 32 样本下
   验证集误差低 39.4 倍、无端点饱和、位移幅度与专家一致”；但它**尚未超过恒等基线**（1.44x）。
   正式训练前建议先做一轮“残差 + 更多数据/更多步”的最小验证。
2. **立刻可做的最小实验**（不改架构、不改部署）：
   - 训练样本从 32 提到 ~200（例如 5–8 个 train 回合按 stride 采帧），步数从 300 提到 800–1000；
   - 仍然只跑 A/B 两组（绝对 / 残差），评测用**同一批**留出帧 + 至少 3 个完整留出回合；
   - 验收线写死：验证集 L1 < 0.009936（恒等）**且** 右臂 7 维分别 < 恒等，否则不算通过。
3. **正则需要盯住右臂**：验证集上残差在左臂≈恒等、右臂明显差于恒等，说明“学到的是左手不动 + 右手噪声”。
   建议下一轮在评测里加入**分臂汇总**与**预测位移/专家位移比值**（本轮已记录，直接复用）。
4. **残差还原链路必须在部署里复核**：本轮评测走 `action_target.joint_command`（`Â = S + Δ̂`）。
   正式部署前需要在 `model.py` 侧同样接线并加一条“绝不把 Δ 直接当绝对角”的断言。
5. 只有上述验收线通过后，才考虑 3000 步正式训练；6000 步与闭环仿真仍不在本轮授权内。

## 附：五个结论（对应任务书第八节）

1. **两组是否真实跑完**：**已通过真实实验验证**。两组均 `result=DONE`，对照器校验通过并生成 `target_comparison.json`。
2. **验证集上谁更低**：**残差**。0.014313 vs 0.563377，**低 39.4 倍**（已通过真实实验验证）。
3. **谁更接近专家动作变化幅度**：**残差**。验证集预测位移 0.005451 vs 专家 0.009936（0.55x）；
   绝对动作是 0.561597（56.5x，灾难性过冲）（已通过真实实验验证）。
4. **谁能超过恒等 / 重复上一动作**：**训练集上只有残差超过**（0.000815 < 0.006407，7.9 倍），
   **验证集上两者都没有超过**（残差 1.44x、绝对 56.7x）。由于本数据上“重复上一动作”≡“恒等”，
   这两条基线等价（已通过真实实验验证）。
5. **是否具备进入 3000 步正式训练的证据**：**有初步证据支持，尚未充分**。
