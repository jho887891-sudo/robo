## 4. "简单策略"基线的真实数值（脚本输出 + 独立复算）

R5 的 `r5_metrics.summarize_prediction` 用 `prior_state = 上一帧 **state**` 计算恒定速度（R4 用的是上一帧
**action**）。这两者在**本数据集**上差别极大，因为 `A[t−1] ≡ S[t]`（实测 `mean|A[t−1] − S[t]| = 0.000000`）。
我另写了一个只读脚本 `diagnostics/r5_baselines.py` 独立复算，与脚本输出交叉验证：

| 策略 | 验证集整体 L1 | 左臂 | 右臂 | 20 回合宏平均 | 与脚本输出 |
|---|---|---|---|---|---|
| `hold_state`（恒等 Â=S[t]） | **0.00480** | 0.00643 | 0.00317 | 0.00480 | 完全一致 |
| `constant_velocity`（**真正的**相邻状态外推 `S[t]+(S[t]−S[t−1])`） | **0.00102** | 0.00123 | 0.00082 | 0.00102 | 完全一致（脚本 0.00102） |
| `train_median_delta`（训练集残差中位数） | 0.00480 | 0.00643 | 0.00317 | 0.00480 | 完全一致（中位数 Δ≈0 → 退化为恒等） |
| 对照：若按 R4 的写法用上一帧 **action** 外推 | 0.00480 | 0.00643 | 0.00317 | 0.00480 | 与恒等**逐位相同**（maxdiff 0.00e+00） |

补充实测：验证帧专家位移 `mean|A−S| = 0.004801`；相邻状态确实在变化 `mean|S[t−1] − S[t]| = 0.004628`，
所以"状态外推"是本数据上**真实有效**的强基线（比恒等好 4.7 倍），不是平凡策略。

两点如实说明（已证实）：

1. **R5 已经修正了 R4 的基线退化**：R4 拿上一帧 action 当 prior_state，导致"恒定速度"≡恒等；
   R5 改用上一帧 state，恒定速度基线变为真正有效的 `0.00102`。这一条独立复算与脚本输出完全吻合。
2. `train_median_delta` **仍然退化**为恒等（本数据集残差中位数约为 0，`median_train(A−S) ≈ 0`），
   因此"超过中位数策略"与"超过恒等策略"在本数据上是同一件事。
3. 由于 60 个验证帧在 20 个回合上**恰好各 3 帧**，回合宏平均与整体均值数值相等；
   这不影响"改进是否覆盖多个回合"的判定（下文按回合逐条比较）。

### 8.3 预测增量的方向正确性（决定性问题）

把生成的 token 还原成物理增量后，与专家增量逐维比较（验证集 60 帧）：

| 指标 | 绝对动作 | 残差动作 |
|---|---|---|
| 预测与真值的逐维平均相关系数 | **+0.696** | **−0.180** |
| 符号一致率 | 0.900 | 0.795 |
| 预测标准差 / 真值标准差 | 0.39058 / 0.38407 | 0.00960 / 0.01043 |

结合 L1 一起读：

- **绝对动作模型并不是"方向全错"**：它跟踪全局姿态的相关系数有 0.70、符号一致 90%，
  但**误差量级 ~0.13 rad 是"每步真实位移 0.0048 rad"的 27 倍** —— 对一个关节伺服而言等于
  "方向大致对但抖 130 mrad"，闭环时毫无用处；
- **残差模型幅度对了（1.04x）但方向不对**：逐维平均相关 **−0.18**（各维 −0.58…+0.30），
  即它输出的是一个"大小正确、方向错误"的增量，因此比"不动"更差（0.00749 vs 0.00480）。
  **这是本轮最重要的负面结论：残差表示没有让模型学会预测未来动作增量。**

| **限制 5** | 未做闭环、未做 3000/6000 步训练（按任务书禁止），也未修改线上 RoboDojo 策略 |
| 本轮新增的辅助脚本 | `diagnostics/r5_sampling_audit.py`、`diagnostics/r5_baselines.py`、`diagnostics/r5_analyze.py`（均为只读 CPU 脚本，未改动 R5 正式代码） |

## 12. 下一步研究建议（基于本轮证据）

核心事实：**问题不在"绝对 vs 残差"，而在"每步信号只有 0.0048 rad，而模型误差分别是 0.13（绝对）/0.0075（残差）"**，
以及残差模型学到的增量与真值**负相关**（−0.18）。据此建议：

1. **把"增量方向正确性"设为一等指标**：下一轮预注册必须包含
   `corr(Δ_pred, Δ_gt) > 0.3`、`sign_agreement > 0.65`；只看 L1 会被"预测不动/预测常数"蒙混过关
   （本轮中位数策略与恒等的 L1 就完全一样）。
2. **先解决"学不到增量"的根因，再加步数**。三个可立刻做的最小实验（都不改架构）：
   - **(i) 数据量**：200 样本 → 全量（80 回合 × 全帧 ≈ 2.9 万帧）或至少 2000 帧，800 → 2000 步。
     当前 200 样本/800 步下，模型在验证集上仍然"右幅度、错方向"，最可能的原因是样本太少导致只能拟合
     平均增量；
   - **(ii) 目标尺度**：残差 bin 宽约 `0.001–0.002 rad`，而每步真实位移 `0.0048 rad`（约 2–4 bin），
     离散化误差与信号同量级。建议把残差目标改为**每维各自的标准化**（或用连续 L1 回归头，OFT 已有实现），
     避免 256-bin 量化把增量吃掉；
   - **(iii) 辅助监督**：在损失中加入"预测增量与真值增量的余弦相似度"项，或在 token 交叉熵之外
     增加连续回归辅助损失，直接惩罚方向错误。
3. **评测必须做回合级 rollout**（至少 3 个完整留出回合），把"单帧平均 L1"换成"回合内累计误差 + 是否到达"。
   本轮已证明单帧 L1 会被"缩放到 0"策略支配。
4. **右臂单独设门槛**：右臂 7 维必须分别优于恒等（本轮 0/7），否则不允许进入正式训练。
5. **不建议现在进 3000 步**：本轮 10 项预注册标准只过 2 项，且残差未超越任何简单策略。
