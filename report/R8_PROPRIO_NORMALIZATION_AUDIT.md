## 0. 摘要（中文）

1. **VERIFIED — R8 现有归一化确实在丢运动信息，而且不是边角情况**：
   V 与 Acc 三个槽位共用**位置**上下界 `pmin/pmax`，导致
   * **平均 30.7% / 31.6%** 的 V / Acc 条目被钉在 `-1`（训练集；开发集 29.8/30.7%，留出集 31.8/32.8%）；
   * **5 个维度**（`left_arm_2, left_gripper, right_arm_1, right_arm_2, right_gripper`）
     的**所有负向运动塌缩为同一个值 -1**（负向幅度信息 100% 丢失，`neg_distinct = 1`）；
   * **零运动不再映射到 0**：映射到 `[0.445, -1.0, -1.0, 0.975, 0.217, 0.341, -1.0, 0.0, -1.0, -1.0, 0.964, 0.093, 0.451, -1.0]`；
   * **16.3%** 的有运动条目与"零运动"取值完全相同（符号无法区分），有符号方案为 **0.0%**；
   * 6/14 维在旧变换下**符号不可分**（微小正向速度与全部负向速度落在同一点）。
2. **VERIFIED — 后果可测量但幅度有限（MLP 代理）**：同分割、同网络、同种子、同预算的受控对照中，
   三种子 DEV 均值 L1：旧方案 **0.001166**，去掉裁剪的对照 **0.001123**，
   **有符号训练集缩放（q99）0.001113**（**−4.5%**），q99.9 变体 0.001137。
   留出集（仅回顾性）0.001230 / 0.001190 / **0.001179** / 0.001192；修正量 R² 0.484 → **0.561**。
   ⇒ **大部分损失来自"裁剪"，偏移本身影响很小**（去掉裁剪即回收 3.7 个百分点）。
3. **选定方案（仅用 DEV 选择，留出集不参与）**：`signed_motion` + `q=0.99`，
   位置槽位保持原样，V/Acc 用 **TRAIN-only** 每维尺度 `s_d = max(q99(|x_d|), 1e-6)`，
   零运动精确映射到 0、符号严格保持；统计量写入检查点元数据。
4. **判定：GPU 训练前的硬性前置条件（不是"可以以后再修"）**。
   以旧方案训练等于**有意丢弃 31% 的运动信号并在 5 个维度上放弃负向幅度**；
   代理任务上的代价是 4.5% L1 / +0.077 R²，尚不构成项目级阻断，
   但对单层线性投影器的 OpenVLA 而言这是**没有理由保留**的缺陷，因此**冻结为方案 B 再上 GPU**。
5. **IMPLEMENTED + TESTED**：`r8_normalization.py`（两模式、TRAIN-only 拟合、元数据往返、
   fail-closed），**16/16 回归测试通过**，其中包含"旧方案 5 维塌缩 / 31% 裁剪 / 零运动非零"
   的真实数据锁定测试，以及审计给出的 `[0,1]` 边界反例。

## 3. A3：受控对照（仅用 DEV 选择方案）

固定：64 训练 / 16 开发 / 20 留出回合、`[S,V,Acc]`→`R`、MLP 42-128-128-14、
Adam 1e-3 / batch 512 / 物理 L1、种子 0/1/2、DEV 早停（400 epoch 上限，patience 40）。

| 方案 | DEV L1（选择依据） | 留出 L1（回顾性） | ×恒速 | V floor | V 不同取值均值 | 留出 R² |
|---|---:|---:|---:|---:|---:|---:|
| A 旧（位置界+裁剪） | 0.001166 | 0.001230 | 0.685 | 0.307 | 7,065 | 0.484 |
| A′ 位置界**不裁剪**（诊断对照） | 0.001123 | 0.001190 | 0.663 | — | 8,592 | 0.534 |
| **B99 有符号 q99（选定）** | **0.001113** | **0.001179** | **0.657** | **0.008** | **10,861** | **0.561** |
| B999 有符号 q99.9 | 0.001137 | 0.001192 | 0.664 | 0.0035 | 11,008 | 0.534 |

* **DEV 排序（唯一合法依据）：B99 > A′ > B999 > A**；B99 比旧方案好 **4.5%**。
* 去掉裁剪（A′）即可回收 **3.7** 个百分点 ⇒ 损失主要是裁剪造成的，位置偏移本身影响小。
* 20/20 回合在全部方案上仍成立；`Δ` 符号一致率 0.972–0.974（几乎不受影响），
  说明**总体方向指标对这类信息损失不敏感**，只有修正量 R² 与 L1 反映出来。
* 留出集数字与 DEV 同序，但**仅作回顾性诊断**，未参与任何选择。

## 4. 判定：是否 GPU 训练阻断项

| 维度 | 结论 |
|---|---|
| 信息是否丢失 | **VERIFIED 丢失**（31% 裁剪、5 维负向幅度全塌缩、16% 与零不可分） |
| 代理任务代价 | **VERIFIED 4.5% DEV L1、+0.077 R²**（不是灾难性，但方向一致且免费可修） |
| 是否阻断 7B 训练 | **作为硬性前置条件：必须先切到方案 B**。这不是"性能优化"，而是"不要在已知有缺陷的输入变换上花 7B 算力" |
| 是否阻断整个 R8 路线 | **不阻断**：修复成本极低（一个缩放向量 + 元数据），且已验证不损害任何指标 |

**给审计的明确回答**：审计提出的风险**在真实数据上成立且频率很高**（不是合成反例）；
但它对**代理任务的实测影响是 4.5%**，因此应表述为
"**必须在 7B 训练前修复的输入缺陷**"，而不是"R8 路线不可行"。
